# ドローン自律飛行プロジェクト

## 目的: 風外乱下でも安定してホバリング・目標到達できる、自律飛行ドローンの強化学習方策を作る
1. 現在の構成: Unityは完全に廃止。Python完結、Genesis World(GPU並列物理シミュレータ)+ rsl-rl-lib(PPO)
2. 物理モデル: GenesisのDroneEntity(Crazyflie 2.X / CF2Xモデル)による4プロペラのRPM直接制御(3軸の単純化された推力モデルではなく、実機に近いローレベル制御)
3. 環境構築: uv
4. 風: Ornstein-Uhlenbeck過程(OU過程)による時間変化する乱気流。エピソードごとに強さ・方向・乱れ方を再抽選(ドメインランダム化)
5. 8192並列でのフル学習に成功済み。現在は報酬モデルを「遠さへの継続減点+生存ボーナス+目標到達ボーナス」の構成に拡張したところ
